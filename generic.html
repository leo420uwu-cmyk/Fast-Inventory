Funciones de la aplicacion

Atajos o ayudas dentro de la aplicacion.

Registro de tienda

registrar tu tienda.

En la parte superior de la aplicacion hay un apartado para crear la tienda *si no hay una tienda registrada no podras registrar ningun produto*

Registrar productos

Registrar nuevos productos en tu inventario.

Para registrar los productos se nesesitaria un codigo de barras o solo la imagen del producto

VENTA DEL PRODUCTO

Una vez registrado el producto con la aplicacion utlizas el codigo de barras para que el producto se registre como vendido o se puede hacer manualmente.

Una vez vendido el producto se hara una lista de los productos vendidos

FECHA DE CADUCIDAD

Al momento de registrar el produto vendra con un apartado para escojer la fecha de caducidad del producto.
